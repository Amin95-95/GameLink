# GameLink · v1 beta 1

Обход на основе **zapret2** для сервисов и WARDOGS в одном приложении для Windows 10/11 x64.

**[Скачать готовую сборку](https://github.com/Amin95-95/GameLink/releases/download/v1.0.0-beta1/GameLink-v1-beta1.zip)** · [Страница выпуска](https://github.com/Amin95-95/GameLink/releases/tag/v1.0.0-beta1)

## Установка

1. Завершите старый GameLink через **«Выход»** в трее и остановите отдельные работающие батники zapret.
2. Распакуйте весь архив в новую папку с правом записи. Запустите `GameLink.exe` и подтвердите запрос администратора. Движок, лицензии и инструкция уже в архиве; отдельный .NET не нужен.
3. На **«Главной»** включите нужные сервисы и нажмите **«Включить обход»**. Первый запуск подбирает стратегию, следующие используют сохранённую.
4. Для WARDOGS откройте **«Расширенный → Игры»**, включите профиль и при чистой установке выполните **«Полный подбор игры»**. Затем нажмите **«Запустить игру»**.

## Подключение к серверам WARDOGS

Если прежний UDP-режим позволяет играть, оставьте его. Если официальный сервер возвращает в меню, сохраните рабочий TLS, закройте игру и выберите **«Новый: QUIC ×1, первые 4 пакета с данными»**. Нажмите **«Применить к игре»**, затем запустите игру заново.

Для описанного профиля оставьте включёнными изучение UDP процесса, совместимость со старым запускателем, прямой RTP Vivox и обход после запуска игры. Общий и игровой движки работают параллельно с независимыми стратегиями.

Успешный официальный матч подтверждён на одной тестовой сети с ALT11 + QUIC. Результат зависит от провайдера и сервера. HTTPS-подбор не подтверждает авторизацию или допуск в матч. Обход DPI не меняет внешний IP.

## Обновление и отчёты

Перед обновлением завершите приложение через **«Выход»** в трее. Распакуйте новую версию в отдельную папку; перенос своей `data` до первого запуска сохраняет настройки.

При сбое сохраните отчёт до остановки движка или смены режима. Файлы находятся в `data/reports` рядом с EXE. Они могут содержать адреса и пути — не публикуйте сырые отчёты. Автоматической отправки разработчику пока нет.

Полная инструкция и лицензии компонентов находятся внутри готового архива. Этот репозиторий используется для публикации сборок.
